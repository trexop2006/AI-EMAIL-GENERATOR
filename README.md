# 📧 AI Email Generator

An AI-powered email generation application built using **Python**, **Streamlit**, and **Google Gemini LLM**. This application generates professional, context-aware emails based on user input.

---

## 🚀 Features

- 📧 Generate Professional Emails
- 📝 Multiple Email Types
  - Formal Email
  - Leave Application
  - Complaint Email
  - Apology Email
  - Thank You Email
  - Job Application
- 🎯 Multiple Tone Options
  - Professional
  - Formal
  - Informal
- 📄 Email Length Selection
  - Short
  - Medium
  - Detailed
- 🤖 AI-Powered Email Generation using Google Gemini
- 📥 Download Generated Email
- ✅ Input Validation
- ⚠️ Error Handling
- 🎨 Clean and User-Friendly Interface

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/trexop2006/AI-Email-Generator.git

cd AI-Email-Generator
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Create a .env file

```env
GENAI_API_KEY=YOUR_API_KEY
```

### Run the Application

```bash
streamlit run app.py
```

---

## 📸 Application Workflow

1. Select the Email Type.
2. Enter the Recipient.
3. Enter the Subject.
4. Enter the Sender Name.
5. Select the Email Length.
6. Provide Additional Details.
7. Select the Tone.
8. Click **Generate Email**.
9. Download the generated email.
